# Мои деньги

Личный трекер доходов и расходов для iPhone. Это веб-приложение (PWA): открывается в Safari, ставится на экран «Домой» и работает как обычное приложение, в том числе без интернета.

- Всё бесплатно: хостинг на GitHub Pages, без серверов и подписок.
- Данные хранятся только на телефоне, никуда не отправляются.
- Сборка не нужна, это обычные HTML, CSS и JavaScript.

## Что умеет

- Доходы, расходы и переводы между счетами, счета в разных валютах (курсы ЦБ обновляются сами)
- **Сканер QR-кода с чека**: сумма и дата подставляются сами, приложение запоминает магазин и его категорию. Есть режим «несколько чеков подряд» и защита от дублей
- **Импорт выписок**: Т-Банк (CSV), Сбер (PDF) и похожие CSV. Категории подбираются автоматически, перед добавлением все операции можно проверить. Повторная загрузка не создаёт дублей
- Быстрый ввод: частые траты в один тап, категория подбирается по комментарию, кнопки «Сегодня» и «Вчера»
- Удаление смахиванием с кнопкой «Отменить»
- Обзор месяца, подсказки (прогноз, сравнение с прошлым месяцем), календарь трат
- Планы: бюджеты на категории, копилки с целями и сроками, учёт долгов
- Регулярные платежи, которые добавляются сами
- ПИН-код и Face ID, фото чека к операции, напоминание о резервной копии
- Крупный текст, светлая и тёмная тема, знакомство при первом запуске
- Резервная копия (вместе с фото) и восстановление, выгрузка в Excel (CSV)

## Как выложить в интернет (GitHub Pages)

Git и программы ставить не нужно, всё делается в браузере.

1. Зарегистрируйся на [github.com](https://github.com), это бесплатно.
2. Нажми **New repository** (зелёная кнопка или «+» вверху справа).
   - Название: например, `money`
   - Видимость: **Public** (на бесплатном тарифе GitHub Pages работает только с публичными репозиториями; в код попадает только само приложение, твои траты хранятся на телефоне и в репозиторий не попадают)
   - Нажми **Create repository**.
3. На странице репозитория нажми ссылку **uploading an existing file**.
4. Открой папку `money-tracker` на компьютере, выдели **всё её содержимое** (не саму папку) и перетащи в окно браузера. Папки `css`, `js` и `icons` перетаскиваются вместе с файлами.
5. Внизу нажми **Commit changes**.
6. Открой **Settings → Pages**. В разделе *Build and deployment* выбери:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/ (root)**, затем **Save**.
7. Подожди 1–2 минуты и обнови страницу. Появится адрес вида
   `https://твой-логин.github.io/money/`.

## Как установить на iPhone

1. Открой этот адрес в **Safari** (именно в Safari).
2. Нажми **Поделиться** (квадрат со стрелкой вверх).
3. Выбери **«На экран „Домой“»**, затем **Добавить**.

Друзьям достаточно отправить ту же ссылку. У каждого будут свои данные на своём телефоне, никто не видит чужие траты.

## Как обновлять приложение

1. Открой репозиторий на GitHub и нажми **Add file → Upload files**.
2. Перетащи туда **всё содержимое** папки `money-tracker` (папки `css`, `js`, `icons`, `vendor` и файлы). Одинаковые файлы заменятся новыми.
3. Нажми **Commit changes**. Через 1–2 минуты приложение на телефоне обновится при следующем открытии с интернетом.

Данные на телефоне при обновлении сохраняются.

## Важно про данные

- Данные живут в хранилище Safari на конкретном телефоне.
- Если удалить иконку с экрана «Домой» или очистить данные Safari, операции пропадут.
- Поэтому раз в неделю-месяц делай **Ещё → Сохранить резервную копию** и сохраняй файл в «Файлы» или iCloud Drive. Восстановить копию можно через **Ещё → Восстановить из копии** (так же можно перенести данные на новый телефон).

## Как запустить на компьютере (для разработки)

Нужен любой локальный сервер, потому что открыть `index.html` двойным кликом не получится. Например, если установлен Python:

```
cd money-tracker
python -m http.server 8000
```

Потом открой в браузере http://localhost:8000.

Вместо этого можно поставить в VS Code расширение **Live Server** и нажать **Go Live**.

## Устройство проекта

```
index.html, manifest.webmanifest, sw.js  — страница, «установка» на телефон, офлайн-режим
css/app.css             — все стили, светлая и тёмная тема
icons/                  — иконки приложения
vendor/pdfjs/           — библиотека pdf.js (Mozilla, Apache 2.0) для чтения PDF-выписок
js/app.js               — запуск и вкладки
js/db.js, js/store.js   — база в браузере и вся логика данных
js/qr.js                — собственный декодер QR-кодов
js/import.js            — разбор банковских выписок и автокатегории
js/lock.js              — ПИН-код и Face ID
js/utils.js, js/ui.js, js/charts.js — форматирование, шторки, графики
js/views/               — экраны: обзор, операции, планы (бюджеты, копилки, долги), ещё,
                          добавление операции, сканер, импорт, знакомство, фото
```

Суммы хранятся в копейках (целыми числами), чтобы не было ошибок округления.
